DNS speed test

Every time you open a new website, your device first asks a DNS server where to find it. A slow DNS server adds a delay before anything starts loading. This test times your current DNS against your router and a few public ones. It takes about 20 seconds.

Everyday lookups are popular sites the server has probably cached, which is what most browsing feels like. Fresh lookups are names it can't have cached, so it has to go and find them.

How to switch

Just this Mac

System Settings → Wi-Fi → Details… next to your network → DNS. Remove the old entries, add the new server's addresses, then press OK.

Every device at home

In your router's settings (192.168.1.1), look under DHCP or LAN for the DNS servers it hands out. Change them there and every device picks them up the next time it reconnects.

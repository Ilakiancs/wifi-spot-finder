How to use it

  • Readings update twice a second, but macOS refreshes signal about once a second, so pause 2–3 s at each place.
  • Hold the laptop the way you'd normally use it. Your body and the lid angle both change the reading.
  • Rough guide: −55 dBm or better is excellent, −65 good, −72 fair, below −80 unreliable.
